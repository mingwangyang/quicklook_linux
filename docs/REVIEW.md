## Linux 与分发边界

按 [XDG 目录规范](https://specifications.freedesktop.org/basedir/0.8/)区分个人配置、数据和缓存；包内程序与资源在 `/usr`。deb 不通过管理员安装脚本进入桌面会话、启动 GUI、重启宿主或修改个人目录。系统文件布局与安装流程参考 [Debian 文件规则](https://www.debian.org/doc/debian-policy/ch-files.html)和[维护脚本规范](https://www.debian.org/doc/debian-policy/ch-maintainerscripts)。

未把 LD_PRELOAD 当作通用稳定 API：它只在用户启用的启动入口生效，并有版本/符号限制。Nemo 默认空格、Nautilus、Dolphin、Yazi 优先使用宿主公开接口。Wayland 的按键权限由合成器掌握，应用不能自行在所有桌面抓取其他窗口的空格。

本包只验证当前 Ubuntu 24.04 / Mint 22.x amd64 依赖栈；其他发行版或架构需相应构建环境。Dolphin 23.08 只支持右键入口，GNOME Files 尚缺本机真实宿主验收。niri 窗口规则优化对其他合成器不自动生效，普通窗口仍可由桌面管理器平铺。
